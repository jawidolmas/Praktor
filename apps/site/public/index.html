“It's not another coding agent. It's the layer above one — deterministic code makes every control-flow decision: spawn, verify, retry, deny. The model is only ever asked to do the coding itself.”

Built so you don't have to babysit it

Isolated by default

Every attempt gets its own git worktree and branch. Nothing the worker does ever touches your working tree directly.

Policy-enforced

A PreToolUse hook denies or asks about force-pushes, prod deploys, destructive SQL and committed secrets — enforced by the harness, not by asking nicely.

Actually verified

The supervisor runs your real acceptance command itself. Work is accepted because a check passed — never because the model said "done."

Checkpoint & respawn

A failed attempt seeds the next worker with what was tried and ruled out, instead of retrying the same dead end in one long context.

the actual point

Tell it what you want.
Then go chill.

The daemon survives closing the terminal — or the whole laptop. A rate limit parks the attempt in place and resumes it once it clears, instead of giving up. And when a worker hits a decision it genuinely can't make alone, it doesn't just block on a prompt you have to be sitting in front of — it reaches you wherever you actually are.

  • Persistent daemon — closing the terminal doesn't stop the work
  • Rate-limit park-and-resume — never burns the attempt budget waiting
  • Answer from anywhere — terminal, dashboard, exec-agent decide, or your phone

How an objective actually moves

  1. 01
    Intake

    exec-agent do "..." resolves the repo and infers a pass/fail check.

  2. 02
    Isolate

    A dedicated git worktree and branch are opened for this attempt.

  3. 03
    Execute, policy-guarded

    A Claude Code worker drives the change; dangerous actions are denied or escalated.

  4. 04
    Verify

    The supervisor runs your real acceptance command. No pass, no accept.

  5. 05
    Checkpoint & respawn

    On failure, a fresh worker starts seeded with what was ruled out.

  6. 06
    Your approval

    exec-agent approve <id> shows the diff. Nothing merges without it.

  7. 07
    Merged

    Lands on your real branch, pushed — a report and an event log behind it.

Quickstart

No API key, no separate billing — it piggybacks on your existing Claude Code login.

install 
# clone, install, and link the CLI globally
git clone https://github.com/jawidolmas/Praktor.git
cd Praktor
npm install
npm link
run 
# say what you want, name the repo
exec-agent do "add a CONTRIBUTING.md in my-project"
  • Node.js 20+
  • git
  • Claude Code CLI, installed and logged in
